# Payment-System-Data-and-GDP-Nowcasting

**A Machine Learning Approach with Implications for CBDC-Era Central Banking**

---

## 📋 Overview

This project explores the intersection of payment system data and macroeconomic indicators through machine learning. It investigates how real-time payment systems data can be leveraged for GDP nowcasting and discusses the policy implications for central bank digital currencies (CBDCs).

The repository contains comprehensive analysis, modeling, and visualization of payment flows as economic indicators, with particular focus on CBDC-era considerations for monetary policy.

---

## 🎯 Key Features

- **Payment System Analysis**: Detailed examination of payment data as economic indicators
- **GDP Nowcasting Models**: Machine learning models for real-time GDP estimation
- **CBDC Implications**: Analysis of central bank digital currency impacts on monetary policy
- **Multi-Tier Modeling**: Hierarchical approach to modeling payment system tiers
- **Data Integration**: Integration of payment systems data with macroeconomic datasets

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook or JupyterLab
- Required Python packages (see notebooks for specific imports)

### Installation

```bash
# Clone the repository
git clone https://github.com/MiaYangM/Payment-System-Data-and-GDP-Nowcasting.git
cd Payment-System-Data-and-GDP-Nowcasting

# Install dependencies
pip install jupyter pandas numpy scikit-learn matplotlib seaborn

# Launch Jupyter
jupyter notebook
```

### Running the Analysis

1. Open `CBDC_Model_tiers_.ipynb` in Jupyter Notebook
2. Follow the markdown documentation and code cells
3. Execute cells in order to reproduce results
